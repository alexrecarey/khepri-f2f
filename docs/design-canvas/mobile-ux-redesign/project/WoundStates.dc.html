Rule
VITA/STR n → wounds 1…n−1, then Unconscious (or NWI / Dogged), then ×2 with Remote Presence, then Dead.
Colour
One ramp per side, light → deep. Dead is always the deepest, in bold white. The ramp stretches to however many states the target has.
Shock
Against 1 VITA without Shock immunity, any wound is Dead: no Unconscious, NWI or Dogged. STR, 2+ VITA and Shock-immune targets are unaffected.
