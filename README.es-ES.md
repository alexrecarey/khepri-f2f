

# Infinity Face Off
### una calculadora de heridas esperadas N4 para Infinity the Game

[Infinity Face Off](https://khepri.netlify.app) es una pequeña aplicación web que permite
a los jugadores de Infinity the Game calcular rápidamente el resultado esperado
de una tirada frente a frente. Está destinada a utilizarse para evaluar perfiles
y para que los nuevos jugadores se hagan una idea de las a menudo contraintuitivas probabilidades de las tiradas frente a frente. 

Es una aplicación web estática de una sola página escrita en JavaScript utilizando React. 
El sitio no requiere ningún backend más que un servidor web para entregar los archivos.
Los cálculos reales de probabilidad de los dados se realizan utilizando la increíble 
librería [icepool](https://github.com/HighDiceRoller/icepool). 
Para ejecutar Python en el navegador web del lado del cliente, utilizamos WASM y la librería Pyodide.

# Instalación

Uso [volta](https://volta.sh/) para sincronizar las versiones de Node y Yarn. Una vez
instalado, un simple comando `yarn` debería ponerlo en funcionamiento.
